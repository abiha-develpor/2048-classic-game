# 🎮 2048 Classic Game

A modern, responsive web-based implementation of the classic 2048 puzzle game, developed as a software engineering project.

## 📌 About

This project recreates the classic 2048 puzzle experience with a clean interface, smooth animations, responsive layout, and touch controls for mobile devices.

The project was developed to strengthen practical skills in JavaScript, HTML, CSS, game logic, and problem solving.

## ✨ Features

- 🎮 Classic 2048 gameplay
- 🧩 4×4 game grid
- 🔢 Tile merging and movement
- 🏆 Score tracking
- 🎯 Game-over detection
- 📱 Responsive design
- 👆 Mobile touch/swipe controls
- ✨ Smooth animations
- 🌐 Web-based interface

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- Git & GitHub

## ▶️ How to Play

1. Open the game in your browser.
2. Use the arrow keys to move the tiles.
3. On mobile devices, swipe in the desired direction.
4. Combine matching numbers to create larger tiles.
5. Try to reach **2048**.
