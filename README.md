# 2048 Classic Game

A modern web-based implementation of the classic 2048 puzzle game, developed as a software engineering project.

## About

This project recreates the classic 2048 puzzle experience with a responsive interface, smooth animations, and mobile touch controls.

The project was developed to strengthen practical skills in JavaScript, HTML, CSS, game logic, and problem solving.

## Features

- 4×4 game grid
- Tile movement and merging
- Score tracking
- Game-over detection
- Responsive design
- Mobile touch controls
- Smooth animations

## Technologies

- HTML5
- CSS3
- JavaScript
- Git and GitHub

## Learning Outcomes

Through this project, I practiced:

- JavaScript programming
- Game-state management
- Arrays and data structures
- DOM manipulation
- Event handling
- Responsive web development
- Problem solving
